# Alento · app de reservas

App web instalable (PWA) para los socios de Alento: horario y reservas con cupo y lista de espera, acceso con código QR, pagos, tienda, mensajes y ficha de cliente con firma.

**Abrir e instalar:** https://savaservicios2026.github.io/Alento-app/

- iPhone (Safari): Compartir → «Añadir a pantalla de inicio».
- Android (Chrome): menú ⋮ → «Instalar aplicación».

Funciona con cuentas reales en Supabase: cada socio se registra con su email y las plazas, avisos y fichas se comparten entre todos. Los pagos desde la app todavía son de prueba.

Demo con datos de ejemplo: https://savaservicios2026.github.io/Alento-app/?demo
